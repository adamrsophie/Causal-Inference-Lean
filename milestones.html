Source
Scope. This library formalizes selected results of causal inference with explicit assumptions. It is not a complete formalization of the field; see Limits.

Milestones

Each entry is a commit on the main branch, oldest first, generated from the git history: the subject and the message of the commit, and the modules it added. Times are as recorded in each commit; the date is shown when it changes.

Every commit on the main branch passed the gate. The procedure page lists its steps: a source scan for placeholders and trust escapes, a build with no warning, and an axiom check that allows only the three standard axioms.
