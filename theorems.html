Fisher's randomization test is valid

design-based inference

Under Fisher's sharp null hypothesis (no unit is affected by treatment), the observed outcomes are the same under every assignment, so the randomization distribution of any test statistic is known exactly. The randomization p-value p then satisfies P(p ≤ α) ≤ α for every α ≥ 0, for any design and any statistic T.

theorem fisher_pValue_valid (po : PotentialOutcomes ι) (hnull : po.SharpNull) (d : Design ι)
  (T : (ι → Bool) → (ι → ℝ) → ℝ) {α : ℝ} (hα : 0 ≤ α) :
  d.prob (fun a => d.fisherPValue T (po.observed a) a ≤ α) ≤ α

Neyman's variance formula

design-based inference

Under complete randomization of n1 treated and n0 control units out of N, the variance of the difference in means over the randomization distribution is S1²/n1 + S0²/n0 − Sτ²/N, where the S² are finite population variances of the treated outcomes, the control outcomes and the unit effects. Since Sτ² is never negative, the usual variance S1²/n1 + S0²/n0 is conservative; the Background page works through a four unit example.

theorem neyman_variance [DecidableEq ι] (po : PotentialOutcomes ι) {n1 n0 : ℕ}
  (hn : n1 + n0 = Fintype.card ι) (hn1 : 0 < n1) (hn0 : 0 < n0) :
  (completeDesign n1 (by omega)).variance (po.diffInMeans n1 n0) =
    po.varTreated / n1 + po.varControl / n0 - po.varEffect / Fintype.card ι

CausalInference.Randomized.neyman_variance in CausalInference.Designs.Randomized.Neyman

theorem neyman_variance_le [DecidableEq ι] (po : PotentialOutcomes ι) {n1 n0 : ℕ}
  (hn : n1 + n0 = Fintype.card ι) (hn1 : 0 < n1) (hn0 : 0 < n0) :
  (completeDesign n1 (by omega)).variance (po.diffInMeans n1 n0) ≤
    po.varTreated / n1 + po.varControl / n0

Unbiased estimation under interference

design-based inference

In the two-stage design of Hudgens and Halloran, groups are first assigned to one of two allocation strategies by complete randomization, and then units within each group are completely randomized according to the strategy of their group. Under partial interference (a unit's outcome depends only on the assignments in its own group), the population estimator is unbiased for the population average potential outcome, for both strategies and both treatment values. The direct, indirect and total effects satisfy TE = DE + IE.

theorem twoStageExpect_popEstimator_completeRandomization
  (Y : (g : G) → (κ g → Bool) → κ g → ℝ) {c : ℕ} (hc : c ≤ Fintype.card G)
  (k : Bool → G → ℕ) (hk : ∀ b g, k b g ≤ Fintype.card (κ g)) (b t : Bool)
  (hcb : if b then 0 < c else c < Fintype.card G)
  (hkb : ∀ g, if t then 0 < k b g else k b g < Fintype.card (κ g)) :
  twoStageExpect (completeRandomization G c hc)
      (fun b g ↦ completeRandomization (κ g) (k b g) (hk b g)) (popEstimator Y b t) =
    popAvg Y (fun g ↦ completeRandomization (κ g) (k b g) (hk b g)) t

The local average treatment effect theorem

identification

With a binary instrument Z and a binary treatment, assume the exclusion restriction, independence of the instrument from the potential variables, monotonicity (no defiers), relevance (a nonzero first stage), 0 < P(Z = 1) < 1 and integrable potential outcomes. Then the Wald ratio, the difference in mean outcomes between the instrument arms divided by the difference in treatment rates, equals the average effect among compliers.

theorem wald_eq_complierEffect [IsProbabilityMeasure μ] (hE : M.Exclusion μ)
  (hI : M.InstrumentIndependence μ) (hM : M.Monotonicity μ) (hR : M.Relevance μ)
  (hY : ∀ z, Integrable (M.YD z) μ) (z : Bool) :
  M.wald μ = M.complierEffect μ z

CausalInference.IVModel.wald_eq_complierEffect in CausalInference.InstrumentalVariables.LATE

counterexample

The assumptions identify only the complier effect: two models with the same observed law, both satisfying every assumption above, have different average treatment effects. Without monotonicity the Wald ratio can differ from both the complier effect and the average effect.

Difference in differences

identification

In the design with two groups and two periods, under consistency, no anticipation, parallel trends in the untreated potential outcomes, overlap and integrability, the average treatment effect on the treated equals the observed difference in differences. The library also proves the exact bias without parallel trends (the trend gap plus the anticipation gap) and group-time identification under staggered adoption.

theorem att_eq_did {μ : Measure Ω} [IsProbabilityMeasure μ] {G : Ω → Bool}
  {Y : Period → Bool → Ω → ℝ} {Yobs : Period → Ω → ℝ} (hG : MeasurableSet (treated G))
  (hcons : Consistency G Y Yobs) (hNA : NoAnticipation μ G Y) (hPT : ParallelTrends μ G Y)
  (hpos : 0 < μ (treated G)) (hlt : μ (treated G) < 1)
  (hY : ∀ t d, Integrable (Y t d) μ) :
  att μ G Y = did μ G Yobs

CausalInference.TwoPeriod.att_eq_did in CausalInference.Designs.DifferenceInDifferences.TwoPeriod

counterexample

Under staggered adoption the static two-way fixed effects coefficient need not average the group-time effects. In an explicit panel where consistency, no anticipation and parallel trends hold and every group-time effect is positive (1, 4 and 1), the coefficient is the unique solution of the normal equations and equals −1/2: the wrong sign, outside the convex hull of the effects.

Manski bounds, with sharpness

identification

With a binary treatment and outcomes known to lie in [lo, hi], and no other assumption, the identified set of the average treatment effect is exactly an interval computed from the observed outcomes and the treatment probabilities, of width hi − lo when the measure is a probability measure. The inclusion is the bound; the equality says that every value of the interval is attained by some model, so the bounds are sharp. Under monotone treatment response the lower end rises to 0.

theorem identifiedSet_ate [IsFiniteMeasure μ] (hA : Measurable A) {y : Ω → ℝ}
  (hy : Measurable y) (hyb : ∀ ω, y ω ∈ Icc lo hi) :
  identifiedSet (boundedModels lo hi) (observed A) (ate μ) y =
    Icc (boundY1 μ A lo y - boundY0 μ A hi y) (boundY1 μ A hi y - boundY0 μ A lo y)

CausalInference.Manski.identifiedSet_ate in CausalInference.PartialIdentification.Manski

theorem identifiedSet_ate_mtr [IsFiniteMeasure μ] (hA : Measurable A) {y : Ω → ℝ}
  (hy : Measurable y) (hyb : ∀ ω, y ω ∈ Icc lo hi) :
  identifiedSet (mtrModels lo hi) (observed A) (ate μ) y =
    Icc 0 (boundY1 μ A hi y - boundY0 μ A lo y)

The mediation formula, and why it needs a cross-world assumption

identification

For a binary treatment and a finite mediator, under treatment ignorability, mediator ignorability given treatment, positivity, integrability and the cross-world independence of Y(a, m) and M(a′), the mean of the nested potential outcome Y(a, M(a′)) equals Σm E[Y | A = a, M = m] P(M = m | A = a′).

theorem integral_nested_eq_mediationFormula [Fintype 𝓜] [IsProbabilityMeasure μ] {a a' : Bool}
  (hA : Measurable P.A) (hMa : Measurable (P.M a)) (hMa' : Measurable (P.M a'))
  (hY : ∀ m, μ (P.M a' ⁻¹' {m}) ≠ 0 → Integrable (P.Y a m) μ)
  (hrandY : ∀ m, μ (P.M a' ⁻¹' {m}) ≠ 0 → IndepFun (P.Y a m) P.A μ)
  (hrandM : IndepFun (P.M a') P.A μ)
  (hmed : ∀ m, μ (P.M a' ⁻¹' {m}) ≠ 0 → IndepFun (P.Y a m) (P.M a) μ[|P.A ⁻¹' {a}])
  (hcross : ∀ m, μ (P.M a' ⁻¹' {m}) ≠ 0 → IndepFun (P.Y a m) (P.M a') μ)
  (hposA : μ (P.A ⁻¹' {a'}) ≠ 0)
  (hpos : ∀ m, μ (P.M a' ⁻¹' {m}) ≠ 0 → μ (P.A ⁻¹' {a} ∩ P.Mobs ⁻¹' {m}) ≠ 0) :
  ∫ ω, P.nested a a' ω ∂μ = P.mediationFormula μ a a'

Latent projection composes

structure

Projecting the latent vertices L1 out of a directed mixed graph and then the latent vertices L2 gives the same graph as projecting out L1 ∪ L2 in one step. The library also proves that projection preserves acyclicity and the ancestor relation among observed vertices.

theorem project_project (G : ADMG V) (L1 L2 : Set V) :
  (G.project L1).project L2 = G.project (L1 ∪ L2)

d-separation and the local Markov property

structure

In an acyclic graph, every vertex is d-separated from its non-descendants given its parents: the graph side of the local Markov property. d-separation is defined by reachability, proved equivalent to the path definition, and decided by a checked procedure on finite graphs.

  G.DSep {v} (G.descendantsOf {v})ᶜ (G.parents v)

The g-formula for treatments over time

identification

In a finite longitudinal model with K time points, assume outcome consistency, sequential exchangeability (in mean independence form) and sequential positivity for a static regime ā. Then the mean of the potential outcome Y(ā) equals Robins's g-formula: the sum over covariate histories of the outcome mean given the history and the regime, weighted by the product of the conditional covariate probabilities at each time. It also equals the recursive form computed by iterated conditional means.

theorem expect_Ypo_eq_gFormula (a : Fin K → 𝒜) (hcons : M.OutcomeConsistent a)
  (hex : M.SeqExchangeable a) (hpos : M.SeqPositive a) :
  M.p.expect (M.Ypo a) = gFormula M.p M.A M.L a M.Y ∧
    gFormula M.p M.A M.L a M.Y = iceGFormula K M.p M.A M.L a M.Y

CausalInference.Longitudinal.Model.expect_Ypo_eq_gFormula in CausalInference.Longitudinal.GFormula

counterexample

When a covariate is affected by the earlier treatment and affects the later one, regression adjustment fails. In an explicit model with two time points the true effect and the g-formula contrast are both 0, while the contrast adjusted for the covariate and the unadjusted contrast are both nonzero.

theorem adjustment_fails :
  p.expect (Ypo true true) - p.expect (Ypo false false) = 0 ∧
    gFormula2 p L0 A0 L1 A1 (fun _ => true) (fun _ _ => true) Y -
      gFormula2 p L0 A0 L1 A1 (fun _ => false) (fun _ _ => false) Y = 0 ∧
    naiveAdjusted ≠ 0 ∧ unadjusted ≠ 0

The sure-thing principle and Simpson's reversal

structure

If an action does not change the distribution of the strata, and raises the probability of an event in every stratum, then it raises the probability in the whole population. A reversal, as in the drug example of Pearl, Glymour and Jewell (recovery rates higher among men and among women, lower in the combined data: 273/350 against 289/350), is therefore possible only when the stratum distribution differs between the arms.

theorem sure_thing_principle {q₁ q₀ e₁ e₀ : V → ℝ} (hq : IsWeights q₀) (hno : q₁ = q₀)
  (h : ∀ v, e₀ v < e₁ v) : standardizedRisk q₀ e₀ < standardizedRisk q₁ e₁

d-separation implies conditional independence

structure

If a finite distribution factorizes along an acyclic graph, then any two sets of variables that are d-separated by a third set are conditionally independent given it. No positivity is assumed. This is the soundness half of the theorem of Verma and Pearl and of Lauritzen, Dawid, Larsen and Leimer; with it, factorization, the local Markov property and the global Markov property are equivalent.

theorem Factorizes.condIndep_of_dSep (hG : G.IsAcyclic) {p : FiniteDist (∀ v, α v)}
  (h : G.Factorizes p) {X Y Z : Finset V} (hsep : G.DSep ↑X ↑Y ↑Z) : p.CondIndep X Y Z

Regression discontinuity

identification

In the sharp design, if the conditional mean of the treated outcome is right-continuous at the cutoff and that of the control outcome is left-continuous, the jump of the observed regression at the cutoff equals the average treatment effect there. In the fuzzy design, with no defiers at the cutoff and continuity of the stratum shares and means, the ratio of the outcome jump to the treatment jump is the average effect for compliers at the cutoff.

theorem sharp_rd_identification {c : ℝ} {m1 m0 : ℝ → ℝ}
  (h1 : Tendsto m1 (𝓝[>] c) (𝓝 (m1 c))) (h0 : Tendsto m0 (𝓝[<] c) (𝓝 (m0 c)))
  {yPlus yMinus : ℝ}
  (hPlus : Tendsto (observedRegression c m1 m0) (𝓝[>] c) (𝓝 yPlus))
  (hMinus : Tendsto (observedRegression c m1 m0) (𝓝[<] c) (𝓝 yMinus)) :
  yPlus - yMinus = m1 c - m0 c

Synthetic control under a factor model

identification

In the noiseless linear factor model, if weights summing to one reproduce the treated unit's covariates and its untreated outcomes in every pre-treatment period, and the pre-treatment factor matrix is invertible, then the synthetic control equals the treated unit's untreated outcome in every period. Without the rank condition an exact pre-treatment fit can coexist with a bias of 1.

    factorOutcome δ θ lam Z₁ μ₁ t = synth w (fun j => factorOutcome δ θ lam (Z j) (μ j)) t)

Missing data: weighting under MAR

identification

If the outcome is missing at random given covariates X (in mean-independence form) and the response propensity π(X) is almost surely positive, then inverse probability weighting recovers the full-data mean: E[1{R} Y / π(X)] = E[Y]. Without MAR the full-data mean is not point identified from the observed-data law.

Sensitivity to hidden bias

design-based inference

In Rosenbaum's model for matched pairs, where the odds of treatment within a pair may differ by at most a factor Γ, the tail probability of the sign statistic under the sharp null is at most the corresponding tail of a binomial distribution with success probability Γ/(1 + Γ). The library also proves the matching lower bound and that the upper bound is attained.

theorem signTestTail_le_binomialTail {S : ℕ} {Γ : ℝ} (hΓ : 1 ≤ Γ) {p : Fin S → ℝ}
  (hp : ∀ s, InSensitivityModel Γ (p s)) (f : Fin S → Bool) (k : ℕ) :
  signTestTail p f k ≤ binomialTail S (Γ / (1 + Γ)) k

Coverage of the Wald interval

design-based inference

If √n (θ̂n − θ) converges in distribution to a normal law with variance σ² > 0 and the standard error estimate is consistent for σ, then the coverage probability of the Wald interval θ̂n ± z σ̂n/√n converges to 1 − α, where Φ(z) = 1 − α/2.

theorem tendsto_waldInterval_coverage {μ : Measure Ω} [IsProbabilityMeasure μ]
  {θhat σhat : ℕ → Ω → ℝ} {θ σ z α : ℝ} (hσ : 0 < σ) (hz : 0 ≤ z)
  (hzα : cdf (gaussianReal 0 1) z = 1 - α / 2)
  {Ω' : Type*} {mΩ' : MeasurableSpace Ω'} {P' : Measure Ω'} [IsProbabilityMeasure P']

What point identification means

structure

A parameter is point identified on a class of models exactly when it factors through the observation: there is a function f of the observed data with θ(m) = f(obs(m)) for every model m in the class. The missing data result above is stated in this framework, and the Manski bounds are stated as identified sets in it.

theorem pointIdentified_iff_exists_factor [Nonempty Θ] :
  PointIdentified S obs θ ↔ ∃ f : O → Θ, ∀ m ∈ S, θ m = f (obs m)
