Methods

A formal statement is only as good as its hypotheses. The library follows a few rules that make every theorem say what it seems to say. Each section states one rule and gives an instance taken from the Lean source on the main branch. Terms are defined on the Background page.

Every assumption is a hypothesis

The rule. A modeling assumption, such as the exclusion restriction, parallel trends or cross-world independence, is a named proposition, and a theorem that uses it takes it as an explicit hypothesis. Nothing is assumed globally, there is no axiom about the world, and the structures that describe a model carry its variables and their measurability, while the modeling assumptions are separate propositions. So the list of hypotheses of a theorem is the complete list of what it assumes, and a reader can check that each one is used for what it says.

Instance. In the instrumental variable model the exclusion restriction, instrument independence, relevance and monotonicity are four separate definitions. Monotonicity, for example:

def Monotonicity (μ : Measure Ω) : Prop := ∀ᵐ ω ∂μ, M.D false ω ≤ M.D true ω

From CausalInference/InstrumentalVariables/Basic.lean

The local average treatment effect theorem then lists them as hypotheses hE, hI, hM, hR, next to the positivity and integrability conditions:

theorem wald_eq_complierEffect [IsProbabilityMeasure μ] (hE : M.Exclusion μ)
  (hI : M.InstrumentIndependence μ) (hM : M.Monotonicity μ) (hR : M.Relevance μ)
  (hY : ∀ z, Integrable (M.YD z) μ) (z : Bool) :
  M.wald μ = M.complierEffect μ z

CausalInference.IVModel.wald_eq_complierEffect in CausalInference.InstrumentalVariables.LATE

Observed data are defined, not assumed

The rule. Where possible, the observed variables are defined from the potential outcomes and the realized treatment, so consistency holds by construction and cannot be forgotten. Where the link between observed and potential outcomes is itself an assumption, it is a separate hypothesis.

Instance. In the instrumental variable model the observed outcome is the potential outcome at the realized instrument and treatment:

def Yobs (ω : Ω) : ℝ := M.Y (M.Z ω) (M.Dobs ω) ω

From CausalInference/InstrumentalVariables/Basic.lean

In the two-period difference in differences design, by contrast, observed outcomes are separate functions linked to potential outcomes by TwoPeriod.Consistency, so that no anticipation is a genuine assumption about the pre period.

Finite and measurable settings are kept apart

The rule. A result about a finite population, or with finitely many values, is stated in a finite setting with finite sums; a result about a superpopulation is stated on a measure space with Mathlib's integrals, conditional measures and independence. The two are not mixed, and module docstrings describe their setting. A finite result is not presented as a general one.

Instance. Randomized designs are finite: a design is a finite set of assignments with nonnegative weights summing to one, and expectations are weighted sums.

structure Design (ι : Type*) where
  /-- The summation set: every assignment that can be drawn lies in it. -/
  support : Finset (ι → Bool)
  /-- The probability of each assignment in `support`; meaningless outside `support`. -/
  weight : (ι → Bool) → ℝ
  weight_nonneg : ∀ a ∈ support, 0 ≤ weight a
  sum_weight : ∑ a ∈ support, weight a = 1

From CausalInference/Designs/Randomized/FinitePopulation.lean

The instrumental variable model, the difference in differences designs and the Manski bounds live on a measurable space with a probability or finite measure instead, and the mediation formula is proved for a finite mediator on a general probability space. The Limits page lists which results are finite only.

Positive results are paired with counterexamples

The rule. Where it is meaningful, an identification theorem comes with a concrete model in which one hypothesis fails and the conclusion fails with it, or with two models that agree on the observed data and disagree on the causal quantity. Such a counterexample is a theorem about explicit objects, checked like any other.

Instance. Difference in differences identifies the effect on the treated under parallel trends; without parallel trends, a two-unit model has difference in differences 1 and effect on the treated 0.

theorem att_eq_did {μ : Measure Ω} [IsProbabilityMeasure μ] {G : Ω → Bool}
  {Y : Period → Bool → Ω → ℝ} {Yobs : Period → Ω → ℝ} (hG : MeasurableSet (treated G))
  (hcons : Consistency G Y Yobs) (hNA : NoAnticipation μ G Y) (hPT : ParallelTrends μ G Y)
  (hpos : 0 < μ (treated G)) (hlt : μ (treated G) < 1)
  (hY : ∀ t d, Integrable (Y t d) μ) :
  att μ G Y = did μ G Yobs

CausalInference.TwoPeriod.att_eq_did in CausalInference.Designs.DifferenceInDifferences.TwoPeriod

theorem cex_did_ne_att :
  Consistency cexGroup cexY cexYobs ∧ NoAnticipation cexMeasure cexGroup cexY ∧
    0 < cexMeasure (treated cexGroup) ∧ cexMeasure (treated cexGroup) < 1 ∧
    ¬ ParallelTrends cexMeasure cexGroup cexY ∧
    did cexMeasure cexGroup cexYobs = 1 ∧ att cexMeasure cexGroup cexY = 0

CausalInference.TwoPeriod.cex_did_ne_att in CausalInference.Designs.DifferenceInDifferences.TwoPeriod

No result rests on a totalized value

The rule. Lean's division is total, with x / 0 = 0, and Mathlib's conditional measure given a null event is the zero measure. An equation between two such values can hold for a trivial reason: both sides are 0. Statements are therefore written so that their content does not depend on these conventions: a quotient appears only with a hypothesis that its denominator is nonzero, and a conditional mean only with a hypothesis that the conditioning event has positive probability, or the conditioning is replaced by conditional mean functions.

Instance. In the local average treatment effect theorem above, relevance (hR, a nonzero first stage) is what makes the Wald ratio a genuine quotient; its docstring explains that without it both sides would be 0. In regression discontinuity, every statement is made through conditional mean functions of the running variable, so that nothing conditions on the null event X = c:

theorem sharp_rd_identification {c : ℝ} {m1 m0 : ℝ → ℝ}
  (h1 : Tendsto m1 (𝓝[>] c) (𝓝 (m1 c))) (h0 : Tendsto m0 (𝓝[<] c) (𝓝 (m0 c)))
  {yPlus yMinus : ℝ}
  (hPlus : Tendsto (observedRegression c m1 m0) (𝓝[>] c) (𝓝 yPlus))
  (hMinus : Tendsto (observedRegression c m1 m0) (𝓝[<] c) (𝓝 yMinus)) :
  yPlus - yMinus = m1 c - m0 c

CausalInference.RD.sharp_rd_identification in CausalInference.Designs.RegressionDiscontinuity.Sharp

Non-identification is a theorem

The rule. A claim that a quantity is not identified is proved, not asserted: either by exhibiting two models that satisfy the assumptions, have the same observed law, and have different values of the quantity, or as the negation of PointIdentified.

Instance. With bounded outcomes alone, the mean of Y(1) is not point identified as soon as the control group has positive probability:

theorem not_pointIdentified_meanY1 [IsFiniteMeasure μ] (hA : Measurable A) (hlh : lo < hi)
  (hpos : 0 < μ.real (treated A)ᶜ) :
  ¬ PointIdentified (boundedModels lo hi) (observed A) (meanY1 μ)

CausalInference.Manski.not_pointIdentified_meanY1 in CausalInference.PartialIdentification.Manski

Finite facts are checked by computation

The rule. Facts about explicit finite graphs (acyclicity, ancestors, districts, d-separation) are decided by procedures proved correct in the library and evaluated by decide, so worked examples are checked rather than claimed.

Instance. The front-door graph X → M → Y with X ↔ Y:

abbrev frontDoor : ADMG (Fin 3) := ofLists [(0, 1), (1, 2)] [(0, 2)]

From CausalInference/Graphical/ADMGExamples.lean

Its acyclicity, the ancestor relation from X to Y, and its districts {X, Y} and {M} are each closed by decide in Graphical.ADMGExamples; d-separation on concrete graphs is checked the same way in the d-separation modules.
