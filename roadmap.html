Source
Scope. This library formalizes selected results of causal inference with explicit assumptions. It is not a complete formalization of the field; see Limits.

Roadmap

One table for the whole project. Each row is an area of causal inference with what it covers, its status, its modules on the main branch, and the areas it depends on. The library does not cover all of causal inference, and this table does not promise that it will: planned rows are intentions, not results.

Three labels, nothing else. On the main branch: the area has modules in the root import file, checked by the gate described on the procedure page. In progress: work is under way and not on the main branch; nothing in it is verified yet. Planned: no work has started. A row on the main branch can still be incomplete: the column "What it covers" describes the area, and the modules listed are what is proved so far.

Order of work

The graphical rows follow their dependencies: d-separation and the Markov factorization come before the global Markov property, which comes with structural causal models before adjustment formulas and the do-calculus, and those before the identification algorithm. The network page draws these dependencies. The design rows are independent of one another and of the graphical rows, and they are extended as their modules land.

An area moves to "on the main branch" in this table only when its first module is imported by the root file on the main branch, so the table cannot run ahead of the code. Its modules then appear on the Reference page and its commit on the milestones page.
